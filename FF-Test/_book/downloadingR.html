3 Downloading R and RStudio

This section contains a guide to downloading and setting up both R and RStudio.

⚠️ It is important that you download both R and RStudio. Download R first, before downloading RStudio

3.1 Downloading R for Windows

R can be downloaded from CRAN (the Comprehensive R Archive Network).

Click “Download R-4.4.1 for Windows”.

When the file has downloaded, open it to run the installation.

We would recommend you agree with the default settings and perhaps consider clicking the boxes to add a desktop shortcut and a Quick Launch shortcut.

3.2 Downloading R for other operating systems

Go to CRAN (the Comprehensive R Archive Network). Select the appropriate operating system from the options given then download the latest release from the following page.

3.3 Downloading RStudio

To download Rstudio, go to the Rstudio webpage. Select the free version of RStudio and click Download.

Click Download RStudio for Windows (or different operating system).
